# cohort-10-java-17240-zainab
Cohort 10 — JAVA Fullstack (JAVA+ReactJS) assignment for zainab mughal

## Backend

Spring Boot API on Java 17. It runs on `http://localhost:8080` with an in-memory H2 database.

Backend development requires JDK 17 installed with `JAVA_HOME` set to it. A JRE alone is not enough to compile the application and tests.

```bash
# Windows (PowerShell)
.\gradlew.bat bootRun
.\gradlew.bat test

# macOS/Linux
./gradlew bootRun
./gradlew test
```
